## What it does
A [HandyNotes](https://www.curseforge.com/wow/addons/handynotes) plugin that pins the spawn points of the **Trove of the Thunder King** treasures on the Isle of Thunder map.

## Features
- 55 trove locations on the Isle of Thunder.
- Tooltip on hover with the name and the exact coordinates.
- Can be toggled from the HandyNotes plugin list like any other plugin.
- Works on Mists of Pandaria Classic and on the original 5.0.4–5.4.8 clients.
- Translated into 20 languages.

## Installation
1. Download the zip from the [latest release](https://github.com/Pirson-s-Addons/HandyNotes_Trove-Thunder-King/releases/latest) or from [CurseForge](https://www.curseforge.com/wow/addons/handynotes-trove-of-the-thunder-king).
2. Extract the `HandyNotes_Trove-Thunder-King` folder into `World of Warcraft/_classic_/Interface/AddOns/`.
3. Restart WoW and enable the addon.

## Usage
- Open the world map on the Isle of Thunder: the troves show up as pins.
- There are no slash commands or options of its own; enable or disable it in the HandyNotes options.

## Notes
- **Requires [HandyNotes](https://www.curseforge.com/wow/addons/handynotes).**
